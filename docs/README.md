# Docs index

One line per document: what it is for, and its status. Every design record and inventory has a
`> **Status:**` line under its title. When the work it describes moves on, update that line.

Status words: **Reference** means a living document to follow. **Built** means the design shipped
and the document records why. **Partly built** means some of it has not shipped. **History** means
it describes a system that has since been replaced.
