# Force visual references

These are the selected-local and entering-local SVGs from the designer-supplied
`Force rendering and frame visualization-2.zip`, final card 2a in
`Force Grid Visuals.dc.html`. The shared SVG definitions are included to make
both drawings standalone. They are reference data, not production components.

`e2e/force-precision.mjs` places the real Angular-rendered force on the same
reference scenery and exports a side-by-side comparison. This deliberately
isolates force styling from unrelated link skins and canvas grid spacing.
